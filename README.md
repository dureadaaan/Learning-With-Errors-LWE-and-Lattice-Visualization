# Learning With Errors (LWE) and Lattice Visualization

A small Python project that visualizes the **Learning With Errors (LWE)** problem — the math behind modern **Post-Quantum Cryptography (PQC)** — using lattices, basis vectors, and noisy inner products.

This started as a Linear Algebra course project connecting core concepts (vector spaces, inner products, linear transformations) to a real-world application in cryptography.

---

## 🔎 What is LWE?

Learning With Errors is a hard math problem that many post-quantum encryption schemes (like **CRYSTALS-Kyber** and **CRYSTALS-Dilithium**) are built on.

The idea in plain terms:

- You have a known vector `a` and a secret vector `s`.
- Normally, computing `⟨a, s⟩` (their inner product) is easy — and if you know enough of these, you could solve for `s`.
- LWE adds a small random **error/noise** `e` to the result:

```
result = ⟨a, s⟩ + e
```

- Without noise (`e = 0`) → the system is easy to solve.
- With noise (`e ≠ 0`) → recovering the secret `s` becomes computationally hard — even for a quantum computer.

That single idea (noise breaks exact linear recovery) is what makes LWE-based encryption quantum-resistant.

## 🔗 Why lattices?

A **lattice** is a grid of points generated by integer combinations of basis vectors. If `b1` and `b2` are basis vectors, every lattice point looks like:

```
point = a·b1 + b·b2   (a, b are integers)
```

LWE can be pictured as a clean lattice point that gets nudged slightly off-grid by noise — and that tiny shift is what hides the secret.

## 🐍 What the code does

**1. Generate a lattice** from two basis vectors:

```python
b1 = np.array([2, 1])
b2 = np.array([1, 3])

points = []
for a in range(-4, 5):
    for b in range(-4, 5):
        points.append(a * b1 + b * b2)
```

**2. Compute a clean vs. noisy inner product:**

```python
a = np.array([3, -2])
s = np.array([1, 2])

clean = np.dot(a, s)
noise = np.random.randint(-1, 2)
noisy = clean + noise
```

**3. Visualize it** — lattice points, basis vectors, and the clean vs. noisy result plotted together (green = exact/clean, orange = noisy), showing how the noise pulls the result off the true lattice structure.

## 🎯 Why this matters

RSA and Diffie-Hellman (used almost everywhere online today) can be broken by a sufficiently powerful quantum computer. LWE is one of the main mathematical foundations being used to build encryption that stays secure even against quantum attacks — and it's built entirely out of linear algebra.
